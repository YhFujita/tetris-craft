# Tetris Craft (テトリス・クラフト)

美しさと爽快感を極めたテトリス風Webパズルゲーム。  
PC・スマートフォンの双方に最適化された操作系、クラシックネオン＆立体木工彫刻の2大スタイル、MIDI音源BGM再生＆ファイル読み込み機能、そして大迫力のライン消去エフェクトを搭載しています。

---

## 🌟 主な特徴

### 1. 2つの極上デザインスタイル
- **クラシックスタイル (Neon Cyber)**:
  - 鮮やかなネオンカラー（シアン、オレンジ、イエロー、グリーン、パープル、レッド、ブルー）。
  - ガラスモーフィズムとサイバーパンクな発光・グロー効果。
- **木目スタイル (Wood Craft 立体彫刻)**:
  - 銘木（檜、オーク、ウォールナット、欅、桜、竹、藍染木）ごとのリアルな風合いと年輪・木目模様。
  - 職人の手彫りのような立体面取り（3D Bevel）と落とし込みシャドウによる、圧倒的な立体感と温もり。

### 2. 選べる2つのゲームモード
- **徐々に加速モード (Speed Up)**: ラインを消すごとにレベルが上がり、落下速度が徐々にスピードアップするスリリングなモード。
- **速度固定モード (Constant Speed)**: 落下速度が変わらず一定に保たれる、落ち着いてパズルを楽しめるリラックスモード。

### 3. 爽快な消去エフェクト
- ライン消去時の白熱フラッシュ＆レーザービーム。
- 飛び散るパーティクル（クラシックでは光の星屑スパーク、木目では木片チップと金継ぎの金粉）。
- 画面振動（スクリーンシェイク）＆ダイナミックなフローティングテキスト（"SINGLE", "DOUBLE", "TRIPLE", "★ TETRIS ★"）。

### 4. 音楽 & MIDI音源再生機能
- **Web Audio API による高音質シンセ音源**:
  - プリセットBGM 1: 「コロブチカ (Tetris Theme A)」
  - プリセットBGM 2: 「木漏れ日 (Woodland Melody)」- 木目スタイルにぴったりのアコースティック調
- **MIDIファイル読み込み**:
  - 手持ちの `.mid` / `.midi` ファイルをドラッグ＆ドロップまたは選択ボタンから読み込み、ゲームBGMとしてリアルタイム演奏可能！
- **充実の効果音 (SE)**:
  - 移動、回転、着地、ハードドロップ、ホールド、ライン消去、4ライン消去ファンファーレ、ゲームオーバー音。

### 5. ハイスコア保存
- 獲得スコアとハイスコアはブラウザのLocalStorageに自動保存され、いつでも記録更新を目指せます。

## 🎮 操作方法

### PC（キーボード）
| キー | 操作 |
| :--- | :--- |
| `←` / `→` | 左右移動（長押しで連続移動） |
| `↑` または `Space` | **回転**（時計回り） |
| `↓` | ソフトドロップ（加速落下） |
| `Enter` または `W` | ハードドロップ（即時着地） |
| `Z` | 逆回転（反時計回り） |
| `C` または `Shift` | ホールド（キープ） |
| `P` または `Esc` | 一時停止 / 再開 |

### スマートフォン（縦画面）
- **スワイプジェスチャー**:
  - 左右スワイプ: 左右移動
  - 下スワイプ: ソフトドロップ
  - タップ または 上スワイプ: 回転
- **画面下部オンスクリーンコントローラー**:
  - `◀` `▶`: 左右移動（長押し対応）
  - `▼`: ソフトドロップ（長押し対応）
  - `⤓ 落下`: ハードドロップ
  - `↻` / `↺`: 回転（時計回り / 反時計回り）
  - `HOLD`: ホールド
  - タップ時の微小バイブレーション（触感フィードバック）対応

## 🚀 GitHub Pages での公開手順

本リポジトリは静的Webサイト（HTML/CSS/JS）として構築されているため、GitHub Pages を有効化するだけですぐに世界中に公開できます。

```bash
# 1. 変更をコミット
git add .
git commit -m "Initial commit: Tetris Craft"

# 2. GitHubにプッシュ
git push -u origin main

# 3. GitHub Pages を有効化（gh コマンドで設定可能）
gh repo edit --enable-pages --pages-branch main
```

公開後は `https://<ユーザー名>.github.io/<リポジトリ名>/` で、スマホや他のPCからブラウザでアクセスして遊ぶことができます。
